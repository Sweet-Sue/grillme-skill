# grill-me：Codex 中文深度访谈 Skill

一个面向 Codex 的中文技能，让 Codex 暂时不急着给答案，而是通过一次一个问题的访谈，帮助你把计划、产品想法、技术设计或实施方案讲清楚。

它会持续检查目标、范围、依赖、风险、边界情况和验收标准，直到双方对方案形成共同理解。

> 这是社区技能，不是 OpenAI 官方项目。

## 功能

- 每轮只问一个最重要的问题，避免一次抛出大量问题。
- 支持结构化选项时，每题提供 2–3 个具体答案，并把最推荐的选项放在第一位。
- 无法显示选项时，先给出一个大概率推荐答案和理由，用户可以直接回复“按推荐”。
- 默认最多询问 8 个高影响问题，可根据项目调整，但绝不超过 20 个问题。
- 优先解决会影响后续决策的关键前置条件。
- 在可以检查工作区、文件、代码或配置时，先自行检查再提问。
- 自动跳过已经回答、可以安全推断或不会改变方案的低价值问题。
- 主动追问范围、非目标、约束、边界情况、失败处理和验收标准。
- 区分已经确认的信息、仍未验证的假设和需要处理的风险。
- 访谈结束后输出目标、决策、假设、风险、验收标准和下一步建议。
- 默认使用中文交流，同时保留 `grill me` 英文触发语。

## 适用场景

- 产品方案评审
- 软件架构和数据库设计
- 数据分析项目规划
- 工作流程设计
- 实施计划和需求澄清
- 个人决策与方案比较

## 安装

### 方法一：Git 克隆

把下面地址中的 `YOUR_GITHUB_USERNAME` 替换成实际 GitHub 用户名：

```powershell
git clone https://github.com/YOUR_GITHUB_USERNAME/grill-me-codex-skill.git "$env:USERPROFILE\.codex\skills\Grill-Me"
```

如果设置了自定义 `CODEX_HOME`，请把仓库放入对应的 `skills\Grill-Me` 目录。

### 方法二：手动安装

1. 下载仓库 ZIP 文件并解压。
2. 将文件夹重命名为 `Grill-Me`。
3. 把它放入 `C:\Users\你的用户名\.codex\skills\`。
4. 确认 `Grill-Me` 文件夹根目录中存在 `SKILL.md`。
5. 新建 Codex 对话；如果技能没有出现，请重启 Codex。

安装后的结构应当类似：

```text
C:\Users\你的用户名\.codex\skills\Grill-Me\
├── README.md
├── SKILL.md
└── agents\
    └── openai.yaml
```

`README.md` 用于 GitHub 项目介绍；Codex 实际执行的规则来自 `SKILL.md`。

## 使用方法

在 Codex 输入框中显式调用：

```text
$grill-me
请用中文逐题检查我的项目计划，找出风险和遗漏。
默认最多问 8 个高价值问题；每题优先给出推荐答案，让我可以直接回复“按推荐”。
```

也可以直接使用自然语言触发：

```text
请压力测试这个数据库设计，一次只问我一个问题。
```

```text
挑战一下我的方案，直到实施需求和验收标准都明确。
```

## 回答选项和问题数量

- 结构化提问工具可用时，Skill 提供 2–3 个具体选项，并把推荐项放在第一位。
- 结构化提问工具不可用时，Skill 不会只给开放问题，而是先给出推荐默认答案和简短理由。
- 如果接受建议，可以直接回复“按推荐”；如果不接受，只需说明需要修改的部分。
- 默认问题预算为 8 个高影响问题。简单任务会提前结束，复杂任务可以调整预算，但硬上限为 20 个问题。
- 达到预算后仍有未决事项时，Skill 会停止提问，并在最终总结中列出这些事项。
- 随时可以说“停止提问，根据现有信息总结”，Skill 应立即结束访谈。

## 工作方式

1. 检查已有上下文，跳过低价值问题，并设置问题预算。
2. 明确目标，以及方案服务的用户或对象。
3. 明确范围和不准备处理的内容。
4. 按依赖关系逐一解决设计或实施选择。
5. 检查风险、边界情况、运行限制和失败处理。
6. 定义完成条件和验收方式。
7. 信息足够、达到预算或用户要求停止时，输出共同理解总结和建议的下一步。
